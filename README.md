# Dizipixel

A modern digital marketing agency website built using HTML5, Bootstrap 5.3, SCSS, and JavaScript.

## Features

- Responsive Design
- Bootstrap 5.3 Grid & Utilities
- SCSS Architecture
- BEM Methodology
- Sticky Navigation
- Hero Banner Carousel
- Services Section
- Portfolio
- Working Process
- Testimonials
- Contact Section
- Optimized Folder Structure

## Technologies Used

- HTML5
- SCSS (Sass)
- Bootstrap 5.3
- JavaScript (ES6)
- jQuery
- Owl Carousel
- Font Awesome

## Installation

git clone https://github.com/yourusername/dizipixel.git

cd dizipixel

npm install

npm run watch-css
